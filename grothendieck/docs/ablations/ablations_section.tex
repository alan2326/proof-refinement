\subsection{Ablations}
\label{sec:ablations}

\paragraph{Setup.}
The framework has two components: the partially formalized blueprint of
Section~\ref{sec:blueprint}, and the agentic system of
Section~\ref{sec:agent}. We ablate each in turn, on both constants, and
measure how much of one refinement step survives. Each case study restarts
from an intermediate checkpoint of its main run and optimizes the same
quantity. For the Grothendieck constant this is the Lemma~5.4 constant $C_r$ of
Section~\ref{sec:grothendieck} restarted at $C_r = 1$, which we want to make
smaller. For the Korenblum constant this is the certified radius $c$, which is
the lower bound on $\mathcal{K}_K$, restarted at $c = 0.35646$, and which we
want to make larger. We run the following four configurations, which share the
same workspace, model, literature, and unmodified evaluator:
\begin{itemize}
\setlength{\itemsep}{0pt}\setlength{\topsep}{2pt}
\item \textbf{Full framework} (reference, both components present): the system
  of Section~\ref{sec:agent}.
\item \textbf{Basic agent} (agentic system reduced to a feedback loop): one
  tool-less model call per iteration; a harness writes the emitted files, runs
  the build and evaluator, and returns the output. The blueprint is kept.
\item \textbf{No agent} (agentic system removed): independent one-shot
  samples, no feedback, best sample kept. The blueprint is kept.
\item \textbf{No partial formalization} (blueprint removed): the full agentic
  system, with the reduction chain and oracles removed; only the published
  bound remains, as an axiom.
\end{itemize}
Every configuration runs until it has at least matched the full framework's
own wall clock and output tokens, and we report its best accepted candidate
among iterations that began within that token budget. On Korenblum the basic
agent was additionally run to three times the budget; it reached $c = 0.35653$,
still below the full framework (Appendix~\ref{app:ablations}). The appendix
gives budgets, traces, compute, and the oracle-audit caveat that makes the
$C_r$ values here incomparable with the final value in
Section~\ref{sec:grothendieck}.

\paragraph{Results.}
Without the partial formalization, nothing improves. The agent wrote plenty of
Lean ($5{,}646$ lines on Korenblum, all evaluator runs passing) but had no
intermediate claim to sharpen, and spent its budget rebuilding one.

Without the agentic system, progress degrades in steps. One-shot samples
already contain a real analytic improvement (four of six accepted on
Grothendieck, all with the same idea), but they stop there. The basic agent
iterates past the first idea and even proposed the full framework's key
structural change, but each build failure cost it a full model call and it
completed that change only at the end of its budget. The full framework
completed it, then built a second change on top, which accounts for the
remaining factor of $1{,}600$. On Korenblum the basic agent re-pinned the
construction it was given, and the full framework found a new criterion in one
iteration.

Each configuration is a single run, and the tool-less configurations ran in the
same runtime with tools disabled, which if anything favors them.
